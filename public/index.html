Elligentt — About

        
v1.0.0 · Arc Testnet · @circle-fin/app-kit

      

      
    

    

    

      
Elligentt is an open-source batch payment dApp built natively on the Arc Network (testnet, Chain ID 5042002). It uses USDC as gas token and features on-chain ElligentPool for swaps, and CCTP v2 for cross-chain bridges.

      

        

          
Stack

          

             Vanilla JS + ethers.js v6
             @circle-fin/app-kit
             ElligentBatch.sol · ElligentPool.sol
             WalletConnect v2
          

        

        

          
Features

          

             Batch up to 500 recipients
             USDC ↔ EURC swap
             CCTP v2 bridge
             On-chain invoices
          

        

      

      

        
        Released under the MIT License. Free to use, fork, and deploy.
      


      
      

        Powered by Arc Network
        
      

      
Arc™ is a trademark of Circle Internet Group, Inc. and/or its affiliates. Elligentt is an independent project built on Arc.
